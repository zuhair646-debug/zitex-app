# لوحة تحكم Zitex — دليل التاجر الشامل

> نسخة v1.5.0 — سبتمبر 2026

هذا الدليل يشرح لك كل قسم في لوحة تحكم التاجر بلغة سهلة ومختصرة.

---

## 🏠 الصفحة الرئيسية
تعرض:
- **إجمالي مبيعات اليوم** — يتحدث كل ساعة
- **البطاقات السريعة**: تسجيل الحضور، الطلبات النشطة، المنتجات، العملاء، المسابقات
- **الاختصارات**: نقطة البيع، الخدمات، التسويق

## 💰 المبيعات والفواتير

### 🛒 نقطة البيع (POS)
- إضافة منتجات للفاتورة من الكتالوج
- تعديل الكميات بضغطتين
- خصم مباشر (نسبة أو مبلغ)
- ضريبة القيمة المضافة 15٪ تُحسب تلقائياً
- طرق الدفع: نقدي، بطاقة، STC Pay، تحويل بنكي
- إصدار الفاتورة وطباعتها أو إرسالها للعميل عبر SMS/واتساب

### 📄 الفواتير
- سجل كامل بالفواتير المُصدَرة
- بحث بالتاريخ أو رقم الفاتورة أو اسم العميل
- إعادة طباعة أي فاتورة سابقة
- تصدير Excel / PDF

## 📣 التسويق والمسوّقون

### 🚀 الإعلانات
- **إعلان مستهدف مجاني**: تنشره ويظهر للعملاء المناسبين حسب المدينة والاهتمام — بدون ميزانية
- إحصائيات المشاهدات والنقرات لكل إعلان
- إيقاف / تفعيل / حذف

### 🤝 برنامج المسوقين بالعمولة
1. **أنشئ حملة**: حدد النسبة % والمكافآت الإضافية
2. **العميل يقدم طلبه**: يعبّئ نموذج مع اسمه، مدينته، متابعينه
3. **أنت توافق أو ترفض** من قسم "طلبات قيد المراجعة"
4. **بمجرد الموافقة**: يتولد رمز إحالة فريد (ZTX-XXXX) للمسوّق
5. **العميل يستخدم الرمز** عند الطلب → **يحصل المسوّق على عمولة تلقائياً**
6. **إحصائيات كاملة** لكل مسوّق: النقرات، التحويلات، المبيعات، العمولات، معدل التحويل، متوسط الطلب، رسم بياني آخر 30 يوم، تحويلاته الأخيرة

### 🎨 البانرات الترويجية
- إضافة صور رئيسية تظهر في الصفحة الرئيسية للعملاء
- ترتيب البانرات بالسحب والإفلات
- إحصائيات المشاهدة لكل بانر

### 🏆 المسابقات والسحوبات
5 أنواع:
- **سحب عام**: أي مستخدم مسجّل ينضم
- **سؤال وجواب**: العميل يجاوب على سؤال ويربح
- **مسابقة شراء**: يجب على العميل شراء بمبلغ معين
- **فيديوهات المستخدمين (UGC)**: العملاء يرفعون فيديو ويصوّت الجمهور
- **تسجيل جديد**: مكافأة للمنضمين الجدد

## 🔧 العمليات

### 🛠 الخدمات
- إنشاء خدمة (تبديل شاشة، بطارية، إصلاح، تركيب، فحص، أخرى)
- **صور متعددة** + وصف مختصر + وصف كامل
- **السعر** + رسم الفحص + مدة الإنجاز
- **الضمان**: عدد الأيام + شروط الضمان
- **استلام + إرجاع من المنزل** بحساب رسم ذكي حسب المسافة (GPS)
- **إشعارات تلقائية للعميل** عند تغيير حالة الحجز

### 📅 حجوزات الخدمات
- عرض جميع الحجوزات + فلترة حسب الخدمة
- تحديث الحالة: قيد الاستلام → مستلم → قيد الإصلاح → جاهز → مكتمل
- **رفع فيديو ≤60 ثانية** يصل للعميل كإشعار خاص
- Toggles: عرضه كتجربة عملاء عام، نشره في السوشيال مع شارة "خدمة صيانة"

### 🏢 الفروع
- إضافة فرع بالإحداثيات (خط الطول والعرض)
- ساعات العمل + أيام العمل
- تفعيل / إخفاء الفرع للعملاء

### 📦 المخزون
- تتبع الكميات لكل منتج
- تنبيهات المخزون المنخفض
- توزيع المخزون على الفروع

## 👥 الإدارة

### 👨‍💼 الموظفون
- إضافة موظف مع رقم هاتفه (كلمة مرور افتراضية: `emp1234`)
- تعيين دور: كاشير، مسوّق، مدير فرع، مندوب توصيل
- تحديد الفرع + الصلاحيات
- تتبع الحضور والمبيعات لكل موظف

### 🎫 تذاكر الدعم
- استقبال شكاوى العملاء
- الرد + إغلاق التذكرة
- إحصائيات وقت الاستجابة

### 👤 العملاء
- قائمة كاملة بالعملاء
- سجل المشتريات + النقاط + المحفظة
- تصنيف: VIP، عادي، جديد

## ⚙️ إعدادات الحساب
- بيانات المتجر (الاسم، الشعار، البيانات التجارية)
- إعدادات الدفع
- إعدادات الشحن
- الاشتراك والفوترة
- **الوضع النهاري / الليلي** — للعميل عبر إعداداته (التاجر يبقى دائماً بالثيم الذهبي الفاخر)

## 🎨 الألوان الأساسية للتطبيق
- **الأسود العميق `#0B0C10`**: الخلفية الرئيسية
- **الذهبي الفاخر `#D4AF37`**: العلامة التجارية (Cyber Gold)
- **الأبيض `#FFFFFF`**: النص الأساسي
- **الرمادي `#A3A6B0`**: النص الثانوي

### وضع العميل (Toggle نهاري/ليلي)
- **نهاري**: خلفية بيضاء + نص أسود + ذهبي للأزرار
- **ليلي**: خلفية سوداء + نص أبيض + ذهبي مضيء
