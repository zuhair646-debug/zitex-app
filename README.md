# Zitex - Tech Store Mobile App
Built by **Smart-Angle**

## Tech Stack
- Mobile App: React Native / Expo SDK 54 / TypeScript
- Backend: FastAPI / Python
- Database: MongoDB

## Setup
### Frontend
```bash
cd frontend
yarn install
npx expo start
```

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001
```
